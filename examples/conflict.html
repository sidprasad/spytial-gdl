Unsatisfiable constraints

When the spatial rules can't all hold at once, spytial-core's IIS report appears below the diagram rather than over it. On an editable diagram it updates as you edit, and clears when the clash is gone.

1 — Satisfiable: no report

a -> b : prereq b -> c : prereq @orientation(selector=prereq, directions=[right])

2 — A clash: delete algo -> intro and the report clears

intro[CS 101]:::Course -> data[CS 201]:::Course : prereq data -> algo[CS 301]:::Course : prereq algo -> intro : prereq @orientation(selector=prereq, directions=[right])
