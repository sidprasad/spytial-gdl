HTML drop-in

One script tag (bottom of this file) plus the <div> blocks below. No build, no init call — every block becomes a live diagram on load.

Read-only — class="spytial-gdl"

A -> B : left A -> C : right @orientation(selector=_links, directions=[below]) @orientation(selector=left, directions=[left]) @orientation(selector=right, directions=[right])

Editable — class="spytial-gdl-editable"
