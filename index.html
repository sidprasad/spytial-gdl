Traditional graph description languages let you write a diagram as lightweight source and delegate its layout to a renderer. That delegation becomes a problem when spatial arrangement itself carries meaning, because the renderer can place elements in ways that contradict it. Spytial GDL pairs a simple graph description language with spatial requirements.

Describe the graph, then state relationships, such as orientation and grouping, that every valid layout must preserve.

Explicit requirements on layout enable interaction beyond rendering: constrained rearrangement, explanations for contradictory requirements, and direct manipulation that edits the underlying graph while preserving the diagram's spatial meaning.
