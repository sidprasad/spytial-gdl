Graph diagrams with layout requirements.

Have you ever described a Mermaid or DOT graph, only to have it laid out all wrong? Spytial GDL is a graph description language that pairs familiar node-and-edge syntax with lightweight, enforced layout requirements—so your diagram’s arrangement carries the meaning you intended.

ExamplesOpen an example in the online playground. EmbedBuilt to be embedded in HTML, MkDocs, Jekyll, Hugo, Docusaurus, and Pollen.

Add requirements where they matter.

  1. Write the graph.

    Start with nodes and edges. Leave layout unspecified when it doesn't matter.

  2. Add layout requirements.

    Specify the spatial relationships that matter. Spytial GDL handles the rest.

  3. Move and edit.

    Drag nodes or edit connections while the requirements continue to hold.

  4. See conflicts.

    When requirements cannot all hold, see which ones conflict.
