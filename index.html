Lightweight
interactive diagrams
in the browser.

Write nodes, edges, and spatial @annotations. Drag the diagram and its layout rules still apply. Embeds in Markdown and HTML.

Try the playground
01

Use this instead of Mermaid

Give your agent a graph and this prompt:

Read https://www.siddharthaprasad.com/spytial-gdl/AGENTS.md
Convert my Mermaid graph to spytial-gdl and embed it in this project. Preserve its nodes, edges, and labels. Check that it renders.
Read the agent guide

For graphs and flowcharts. Sequence diagrams, Gantt charts, and other Mermaid diagram types need a different renderer.

02

Add it to a page

Paste this into an HTML page served by your site or local server:

<div class="spytial-gdl">
mul[×] -> div[÷] : lhs
mul -> three[3] : rhs
div -> six[6] : lhs
div -> two[2] : rhs

@orientation(selector=lhs, directions=[below, left])
@orientation(selector=rhs, directions=[below, right])
</div>

<script type="module"
  src="https://cdn.jsdelivr.net/npm/spytial-gdl/src/auto.js"></script>
See it running Set up your docs site

For Markdown, add the same script to your site template and use a spytial-gdl code fence. GitHub README files display the source only.
