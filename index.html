Graph diagrams with layout requirements.

Spytial GDL is a lightweight, web-native graph description language for spatially meaningful diagrams.

It pairs the declarative node-and-edge descriptions familiar from Mermaid and DOT with layout requirements drawn from the Spytial diagramming language.

Space is part of what a diagram says.

Ever described the right graph in Mermaid or DOT, only to find that its layout obscured the point?

Effective diagrams use space to make structure perceptible. When you cede layout entirely to a renderer, you cede control over part of what makes the diagram effective.

Authors often steer the result with invisible edges, ranks, subgraphs, or changes to source order. These workarounds can be brittle as the graph changes. They also put elements in the source that exist only to influence placement, alongside the nodes and edges of the actual graph.

Add requirements where they matter.

  1. 01

    Start with the graph.

    When spatiality is incidental, write only nodes and edges.

  2. 02

    Add layout requirements.

    Specify only the spatial relationships that matter. Spytial GDL handles the rest of the layout.

  3. 03

    Graphs are interactive.

    Drag nodes around without violating your layout requirements.

  4. 04

    See conflicts.

    If no layout can satisfy the requirements, Spytial GDL shows which ones are incompatible and how they fail.

  5. 05

    Edit the graph.

    In editable diagrams, the same requirements guide direct manipulation as the graph changes.
