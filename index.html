Graph diagrams with layout requirements.

Have you ever described a Mermaid or DOT graph, only to have it laid out all wrong? Spytial-GDL pairs the familiar node-and-edge syntax of these graph description languages with lightweight layout requirements. Its layout requirements keep spatial relationships in place as readers move nodes.

  • Examples Try out some examples online.
  • Web Native Easy to embed in HTML, Markdown, MkDocs, Jekyll, Hugo, Pollen, Docusaurus, ...

Add requirements where they matter.

  • Describe the graph. Start with nodes and edges. Leave layout unspecified when it does not matter.
  • Add layout requirements. Specify only the spatial relationships that matter.
  • Enforced in real time Generated graphs are interactive! You can drag elements around, with confidence that the layout requirements will always hold.
  • Inspect conflicts. If requirements conflict, the diagram identifies the affected rules and shows a feasible layout.
