Graph diagrams with layout requirements.

Have you ever described a Mermaid or DOT graph, only to have it laid out all wrong? Spytial-GDL pairs the familiar node-and-edge syntax of these graph description languages with lightweight layout requirements. It is backed by a spatial semantics that ensures that any rendered graph lays out as you specified, and fails loudly and usefully when these requirements cannot be met.

ExamplesTry out some examples online. Web NativeEasy to embed in HTML, Markdown, MkDocs, Jekyll, Hugo, Pollen, Docusaurus, ...

Add requirements where they matter.

  1. Describe the graph.

    Start with nodes and edges. Leave layout unspecified when it doesn't matter.

  2. Add layout requirements.

    Specify only the spatial relationships that matter.

  3. Enforced in real time

    Generated graphs are interactive! You can drag elements around, with confidence that the layout requirements will always hold.

  4. Fail loudly and usefully!

    When requirements cannot all hold, you get an error report, and a counterfactual diagram that helps explain why.
